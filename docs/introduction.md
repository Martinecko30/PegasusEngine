# Introduction

**PegasusEngine** is a C# engine project designed around a component-based object model and editor tooling.

The solution is organized into multiple projects, separating the engine runtime, editor functionality, and export-related code.

## Goals

PegasusEngine aims to provide:

- A reusable runtime engine foundation.
- A component-based object system.
- Editor panels and tools for development workflows.
- Generated API documentation using DocFX.
- A foundation for building, editing, and exporting projects.

## Project Structure

The solution contains several main projects:

| Project | Purpose |
|---|---|
| `PegasusEngine` | Core engine runtime code. |
| `PegasusEditor` | Editor interface and tooling. |
| `PegasusExport` | Export/build-related functionality. |
